# Portfolio website

A responsive, single-page portfolio site built with plain HTML, CSS, and JavaScript. No build tools or dependencies are required.

## Personalize it

Open `index.html` and replace the example copy before publishing:

- `Your Name` and `[your role]` in the page title, navigation, and intro.
- The about paragraph, location, interests, and skill tags.
- Project titles, descriptions, categories, and preview artwork.
- `hello@example.com` with your email address.
- LinkedIn URL with your profile link (the GitHub link currently points to `shanvijaygit`).
- The page description in the `<meta name="description">` tag.

The project previews are CSS illustrations, so you can keep them or replace them with screenshots of your work. The site works on mobile and desktop and can be previewed by opening `index.html` in a browser.

## Publish with GitHub Pages

In the repository, open **Settings → Pages**, choose **Deploy from a branch**, select `main` and the `/ (root)` folder, then save. GitHub Pages will provide the published URL after deployment finishes.
